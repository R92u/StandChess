# StandChess

Шахматы для двоих с тринадцатью стендами из JoJo. У каждого игрока один стенд на партию. Выберите его при создании партии или входе в комнату. Партия за одной доской работает при открытии `index.html`. Для сетевых комнат нужен сервер с Node.js 22 или новее.

Echoes ACT 3 прижимает одну фигуру соперника на его следующий ход. Король невосприимчив. Прижатая фигура продолжает защищать свои клетки. Crazy Diamond вместо хода возвращает взятую пешку, коня, слона или ладью на её исходную клетку, если она свободна. При взятии расстояние до своего короля должно составлять не более трёх ходов короля. Оба стенда тратят 100 маны.

При активации Echoes фигура сжимается под ударом и остаётся прижатой до конца действия. Crazy Diamond собирает фигуру из осколков на её стартовой клетке. Звук обеих анимаций отключается общей кнопкой в меню.

Super Fly действует с начала партии без затрат маны. Если его выбрал хотя бы один игрок, на случайной свободной клетке рядом с фигурой появляется одна общая башня. Зона включает клетку башни и соседние клетки, в том числе по диагонали. После каждого хода в зоне должна оставаться хотя бы одна фигура любого цвета. На клетку башни можно встать, через неё можно ходить. Кнопка на карточке стенда переключает подсветку границы. Ранее сохранённые партии сохраняют исходный радиус в три клетки.

Установка метки скрыта в журнале и перемотке, мана Киры видна только владельцу. В течение трёх ходов соперника попытка взять носителя уничтожает нападающего и расходует его ход. При взятии оригинала или копии исчезает и вторая фигура. Кнопка «Снять наклейку» убирает копию сразу, бесплатно, даже во время хода соперника. Каждый игрок начинает с нуля и получает 10 маны за свой шахматный ход. Для Gold Experience и Heaven’s Door предел составляет 150, для остальных активных стендов — 100. В отладке есть готовая позиция для каждого стенда и предпросмотр анимаций со звуком. Кнопка «Случайное бедствие» показывает один из трёх эффектов Wonder of U. В сетевой партии сервер выбирает происшествие для обоих игроков.

## Шах, мат и пат

Клиент и сервер используют одни правила. Движок по очереди пробует ходы и проверяет безопасность короля в получившейся позиции. Он учитывает реальный способ атаки переписанных фигур, призрачные клетки, выстрел Enigma, исчезновение связанных фигур и границу Super Fly. Для рокировки также проверяется промежуточная клетка короля.

Когда обычных ответов нет, движок проверяет доступные по мане способности и допустимое снятие наклейки. Например, Kiss может поставить копию между королём и атакующей ладьёй, а Heaven’s Door — лишить эту ладью прямолинейной атаки. Если спасения нет и король под шахом, это мат. Если допустимого продолжения нет и шаха нет, это пат.

## Оценка и разбор партии

Шкала рядом с доской показывает примерный перевес в пешках. Плюс означает преимущество белых, минус — чёрных. При перемотке шкала показывает выбранную позицию. При мате король проигравшей стороны наклоняется, рядом с ним появляется знак мата, а король победителя получает корону. При включённом системном уменьшении движения значки появляются сразу.

После окончания игры нажмите «Разобрать партию». Для каждого действия анализатор перебирает легальные ходы и доступные способности, затем проверяет ближайшие ответы на несколько сильнейших вариантов и на сыгранный ход. Он учитывает материал, угрозы, ману и эффекты стендов, в том числе дополнительные ходы The World. Это приближённая оценка StandChess. Процент точности показывает, насколько сыгранные действия сохраняли оценку по сравнению с найденным продолжением.

Нажатие на строку разбора открывает доску после этого действия. Скрытые активации Bites the Dust пропускаются. Сработавшая ловушка и стёртые King Crimson ходы получают отдельную отметку и не влияют на процент точности.

## Запуск

Веб-версия доступна на [GitHub Pages](https://r92u.github.io/StandChess/) и [Render](https://standchess-r92u.onrender.com/). Обе версии используют общий сервер комнат на Render.

### Android

[Скачать подписанный APK для Android 8 и новее](https://github.com/R92u/StandChess/releases/download/android-v1.0.0/StandChess-1.0.0.apk). Приложение открывает веб-версию с GitHub Pages в системном Android WebView. Изменения игры из ветки `main` появляются в приложении после публикации Pages и обновления веб-кеша. Пакет содержит и локальную версию для игры вдвоём без интернета. В ней кнопка «Проверить обновление» снова открывает сайт, а сохранение партии остаётся в том же хранилище.

Для приглашения нажмите «Онлайн», выберите стенд и создайте комнату. В Android появится QR-код. Камера второго телефона откроет приглашение в установленном приложении или браузере. При необходимости переключитесь на «Ссылка». В QR-коде содержится только адрес комнаты.

Для сборки Android-оболочки нужны JDK 17 и Android SDK Platform 35. Запустите `gradlew.bat :app:assembleDebug` из каталога `android` (в Linux/macOS — `./gradlew :app:assembleDebug`). Для подписанной сборки задайте `STANDCHESS_KEYSTORE` и `STANDCHESS_KEY_PASSWORD`, используйте ключ с именем `standchess` и задачу `:app:assembleRelease`. Обновления самой оболочки выпускаются отдельным APK с тем же ключом подписи.

### Локальный сервер

```sh
node server.js
```

По умолчанию игра открывается на `http://localhost:18473`. На хостинге сервер использует порт из переменной `PORT`. Маршрут `/healthz` служит для проверки готовности.

В меню «Онлайн» создайте комнату и скопируйте приглашение. Создатель играет за белых, второй игрок занимает место чёрных. При перезагрузке страницы браузер возвращает игрока на его место. Для игры через интернет оба игрока должны открыть один публично доступный сервер.

Сервер хранит комнаты в памяти одного процесса. Комната закрывается при перезапуске сервера или через 24 часа без обращений. Локальная партия хранится отдельно в браузере. Источники графики, эффектов и звука указаны в `CREDITS.txt`.
